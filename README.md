Propertyware is a cloud-based property management software platform offering a REST API for managing properties, units, leases, tenants, work orders, maintenance requests, financial transactions, and owner reports. The open API enables two-way data exchange with third-party systems and supports custom integrations for single-family and low-density rental portfolios.

**Areas:** Property Management · Real Estate · Rental Properties · Single-Family Rental · Leases · Tenants · Maintenance · Work Orders · Financial Transactions · Owner Reports

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Propertyware: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
